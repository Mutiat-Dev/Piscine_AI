# Apply prompting to professional use cases.

# Prompt 1

    Create a 3-sentence professional summary for a software engineer skilled in Python and cloud systems

# Model output

    Results-driven Software Engineer with strong expertise in Python development and cloud-based systems architecture. 
    
    Experienced in designing, deploying, and maintaining scalable applications using modern cloud platforms, with a focus on performance, security, and reliability. 
    
    Adept at collaborating in cross-functional teams to deliver efficient, high-quality solutions that support business objectives.

# prompt 2

    Create a 4 sentence professional summary for a geophysicist applying for the position of a seismic interpreter at chevron

# Model output

    Accomplished Geophysicist with extensive experience in seismic data acquisition, processing, and interpretation for hydrocarbon exploration. 
    
    Skilled in using industry-standard software and techniques to analyze subsurface structures and identify potential reservoirs. 
    
    Proven ability to collaborate with multidisciplinary teams to deliver accurate geological models that inform strategic exploration decisions. 
    
    Highly motivated to apply technical expertise and analytical skills as a Seismic Interpreter at Chevron to support efficient and safe resource development.


# Observation

    For the first output, it is short and concise because of the instruction from the prompt to stick to 3 sentences. The second prompt was more lengthy than the first because the prompt included the instruction, 4 sentences. One can see the difference in both output as the roles are different and the skills and expertise required are different.
